# custom-extensions

Initial test extension to make adding translations for tuta devs faster & maybe more in the future.

## Installation

- Run `gradle buildPlugin`
- Install Manually:

  Download the [latest release](https://github.com/das-tuta/custom-extensions/releases/latest) and install it manually using
  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>⚙️</kbd> > <kbd>Install plugin from disk...</kbd>
